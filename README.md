## Lokaal runnen

```bat
pip install -r requirements.txt
python gameloop_magic_booster_pro.py
```

## EXE bouwen

```bat
build_exe.bat
```

Output:

```text
dist\GameLoopMagicBoosterPro.exe
```

## GitHub Actions

Upload alle bestanden naar GitHub. De workflow zit in:

```text
.github/workflows/build-windows-exe.yml
```

Ga daarna naar **Actions > Build Windows EXE > Run workflow**.

## Belangrijk

Run de EXE als Administrator voor maximale werking.

Deze tool gebruikt alleen normale Windows performance instellingen. Geen cheats, injecties, memory patches of anti-cheat bypass.
